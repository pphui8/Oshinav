## How to Find Documentation for a Functionality

The documentation is currently flat under `./docs`; there are no topic subdirectories yet.

1. Read `README.md` and `agents.md` for an overview of the project.
2. Check `./docs/index.md` to understand the overall documentation structure.
3. Open the relevant document listed in `./docs/index.md`.
